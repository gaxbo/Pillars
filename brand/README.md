# Pillars brand

The mark is three pillars filled to different levels, like a week's goals
adding up. It sits on a 24-unit grid: 5u pillars, 1.5u gutters, 1u corners.
One vertical gradient spans the whole mark, so the fuller a pillar, the
lighter its top.

Every file here is generated by `npm run brand` (`scripts/build-brand.mjs`),
which also copies the ones the sites use into `public/` and `landing/public/`.
Change the script, not the files. It also stamps each icon's fingerprint into
both `index.html` files (`favicon.svg?v=…`), because browsers keep an old
favicon long after it changes, reloads included.

## Which file

| File | For |
| --- | --- |
| `pillars-logo.svg` | The logo on light backgrounds. The landing nav and footer, and the app's sign in and sign up. |
| `pillars-logo-dark.svg` | The logo on dark backgrounds. |
| `pillars-mark.svg` | The mark alone, on light. |
| `pillars-mark-dark.svg` | The mark alone, on dark. |
| `pillars-mark-flat.svg` | No gradient, for anything that can't carry one: tiny sizes, stickers, embroidery. |
| `pillars-mark-mono.svg` | One colour. Takes the surrounding text colour, for print and engraving. |
| `pillars-icon.svg` | The app icon, rounded. Both sites' `favicon.svg`. |
| `pillars-icon-square.svg` | Full-bleed, for platforms that round the corners themselves. |
| `pillars-icon-512.png` | Profile pictures, app listings. |
| `apple-touch-icon.png` | The iPhone home-screen icon, 180px. |
| `pillars-og.png` | The link preview, 1200×630. `landing/public/og.png`. |

## Type

The wordmark is Instrument Sans SemiBold, lowercase, tracked -0.045em, and
outlined, so no file depends on the font being installed. The mark in the
logo is exactly as tall as the l, sitting on the wordmark's baseline.

## Using it

- Keep clear space around the logo of at least half the mark's height.
- Smallest sizes: the logo 20px tall, the mark 16px. Below that, use the
  icon.
- Don't recolour, stretch, rotate, outline or add shadows. For one colour,
  use the mono mark.
